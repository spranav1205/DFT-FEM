**Goal:** Develop a scalable **fast-diagonalization (FD)-based preconditioner for a matrix-free, conforming finite-element Poisson solver on locally refined meshes with hanging nodes**, with emphasis on performance on modern CPU/GPU architectures. The desired construction should exploit exact tensor-product/FD structure wherever the mesh is regular, while handling non-tensor-product refinement interfaces separately, and should ultimately reduce CG iterations and total solve time relative to Jacobi.

**Methods explored:** First, a **coarse structured mesh + FD correction** applied to the relevant DOFs was tested, but it performed no better than Jacobi; adding Jacobi on the remaining DOFs did not improve it. Second, the matrix was split into additive pieces and a **Neumann-series approximation** was considered, but the resulting matrices were singular; attempts to regularize them destroyed the tensor decomposition needed by FD, so this direction was abandoned. A further planned baseline is an **intermediate mesh**—finer than the original coarse mesh but not fully refined—combined with FD.

**Current method:** The main direction is **overlapping additive Schwarz with FD-solvable local subproblems**. First validate the Schwarz architecture on a completely uniform mesh using CG: split the domain into **4 or 8 structured patches with 1-cell overlap**, initially assemble the local patch matrices and solve them directly (no FD yet). Use the symmetric weighted form

$$
M^{-1}r=\sum_i R_i^T W_i A_i^{-1}W_iR_i,
\qquad
\sum_iR_i^TW_iR_i=I,
$$

so overlapping DOFs are not double-counted; for two-way overlap, use weight \(1/2\) on shared DOFs. Compare against CG+Jacobi in iteration count, preconditioner cost, and total time. Once the architecture is shown to improve convergence, replace each local inverse \(A_i^{-1}\) by the existing FD solver without changing the Schwarz structure.

**Nonuniform/hanging-node extension:** The intended extension is to **locally refined meshes where FD patches are chosen only from rectangular/tensor-product regular regions**, leaving the coarse/fine hanging-node interface and any irregular interior DOFs outside the FD subproblems. The remaining DOFs can initially be handled by Jacobi or another cheap smoother. The key unresolved implementation issue is how restriction/injection \(R_i,P_i\) should treat hanging-node constraints in a matrix-free operator, since constraints are not incorporated into a global assembled matrix. For a \(1{:}4\) refinement interface, the current preference is to initially keep the FD region away from the irregular interface (e.g. one fine-cell layer) and experiment with larger penetration; patch overlap should be treated as a geometric/physical concept rather than blindly matching cell counts across different \(h\). The important research question is therefore not “solve nonuniform meshes with Schwarz” in general—that is established—but **whether a useful matrix-free FD-Schwarz preconditioner can be constructed for locally refined hanging-node FEM meshes by covering maximal tensor-product regions with overlapping FD patches and separately treating uncovered/interface DOFs**. Potential novelty lies in this particular FD-specific construction, not in Schwarz or FD-Schwarz themselves.
